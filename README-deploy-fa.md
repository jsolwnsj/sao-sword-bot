# دانلودر تلگرام — اینستاگرام + پورن‌هاب

ربات تلگرام با پایتون که لینک اینستاگرام (ریلز/پست عمومی) و پورن‌هاب
را می‌گیرد و همان‌جا توی همان چت برمی‌گرداند.
هم توی پی‌وی کار می‌کند، هم توی گروه.
یوتیوب توی این نسخه نیست.

## چی داره

- `/start` و `/help` با راهنمای فارسی
- تشخیص لینک `instagram.com` و `pornhub.com` / `www.pornhub.com`
- اینستاگرام و پورن‌هاب: دانلود مستقیم و ارسال ویدیو/عکس
- سقف سخت تلگرام و مدیریت فایل بزرگ: اول کیفیت پایین می‌آید
  (۷۲۰p، بعد ۴۸۰p، بعد ۳۶۰p). اگر باز هم فایل بالای ۵۰ مگ بود،
  دو راه هست:
  - اگر MTProto (Telethon) فعال باشد: فایل بزرگ مستقیم با حساب
    کاربری تا ۲ گیگابایت فرستاده می‌شود و نیازی به تیکه‌تیکه کردن نیست.
  - اگر فعال نباشد: با ffmpeg به قسمت‌های زیر ۴۸ مگ تقسیم می‌شود و
    قسمت‌ها به ترتیب با شماره قسمت (قسمت ۱ از ۳ و...) فرستاده می‌شوند.
  «مستقیم فرستادن» با Bot API سقف ۵۰ مگ تلگرام را دور نمی‌زند؛
  راه واقعی برای فایل بزرگ، MTProto است (بخش ۵ را ببین).
- خطاها به فارسی و کوتاه
- فقط محتوای عمومی، بدون لاگین و بدون کوکی

## فایل‌ها

| فایل | چیه |
|---|---|
| `bot.py` | کد اصلی ربات (polling) |
| `requirements.txt` | `python-telegram-bot` ،`yt-dlp` و `telethon` |
| `Dockerfile` | پایتون ۳٫۱۱ + ffmpeg |
| `railway.json` | دیپلوی با Dockerfile |
| `start.sh` | اجرای ربات (استفاده نمی‌شود مگر لازم باشد) |

## ۱. ساخت ربات با BotFather

1. توی تلگرام برو به `@BotFather`
2. بزن `/newbot` و اسم و یوزرنیم ربات رو انتخاب کن
3. توکن رو کپی کن — به هیچ‌کس نفرست، فقط توی Railway واردش کن

### برای کار کردن توی گروه (مهم)

1. توی `@BotFather` بزن `/setprivacy`
2. ربات رو انتخاب کن و بزن `Disable`
3. بعد ربات رو به گروه اضافه کن؛ دیگه نیازی نیست ادمین باشه،
   فقط عضو گروه باشه کافیه.

## ۲. پوش به گیت‌هاب

یه ریپوی جدید بساز و محتوای همین پوشه رو توی ریشه ریپو بذار
(`bot.py` ،`requirements.txt` ،`Dockerfile` ،`railway.json`).

## ۳. دیپلوی روی Railway

1. برو به railway.com و با گیت‌هاب لاگین کن.
2. New Project → Deploy from GitHub repo → همون ریپو رو انتخاب کن.
3. Railway خودش Dockerfile رو پیدا می‌کند و بیلد رو شروع می‌کند.
4. توی سرویس، تب Variables، این رو اضافه کن:
   - `BOT_TOKEN` = توکن ربات تلگرامت
   - (اختیاری، برای فایل بزرگ — بخش ۵ را ببین)
5. صبر کن دیپلوی تمام بشه؛ توی لاگ باید ببینی:
   `Downloader bot started (polling).`
6. دامین لازم نیست؛ ربات با polling کار می‌کند و نیازی به وب‌هوک نیست.
   اگه قبلاً وب‌هوک روی همین توکن ست بوده، اول
   `deleteWebhook` رو بزن تا polling کار کنه.

## ۴. تست

- توی پی‌وی ربات `/start` رو بزن.
- یه لینک ریلز اینستا یا ویدیوی پورن‌هاب بفرست.
- ویدیوهای خیلی طولانی ممکنه چند قسمت بیان؛ هر قسمت شماره داره.

## ۵. ارسال فایل بزرگ با MTProto / Telethon (اختیاری)

سقف ۵۰ مگابایت فقط برای ربات‌هاست (Bot API). با حساب کاربری
تلگرام و MTProto می‌شود تا ۲ گیگابایت فرستاد. این بخش اختیاری است؛
اگر این متغیرها را ست نکنی، ربات همان‌طور که هست کار می‌کند و
فایل بزرگ را تیکه‌تیکه می‌کند.

### ۵٫۱ گرفتن API ID و API Hash

1. با مرورگر برو به https://my.telegram.org و با شماره تلگرامت وارد شو.
2. برو به **API development tools**.
3. یک اپ بساز (اسم و پلتفرم را هر چیزی بزن) و `api_id` و `api_hash`
   را کپی کن.
4. این دو مقدار را برای خودت نگه دار؛ `api_hash` مثل رمز است و
   نباید برای کسی بفرستی.

### ۵٫۲ ساختن StringSession (فقط یک بار، روی کامپیوتر خودت)

این اسکریپت کوتاه را روی کامپیوتر خودت اجرا کن (نه توی چت و نه
برای کسی نفرست):

```python
from telethon import TelegramClient
from telethon.sessions import StringSession

api_id = 12345678          # همان api_id خودت را بزن
api_hash = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"  # همان api_hash خودت را بزن

with TelegramClient(StringSession(), api_id, api_hash) as client:
    print(client.session.save())
```

اولین بار شماره تلفنت را می‌خواهد و بعد کد ورود تلگرام را. در
آخر یک رشته طولانی چاپ می‌کند — همان StringSession است.

> ⚠️ این رشته، **ورود کامل به حساب تلگرامت** است؛ هر کسی آن را
> داشته باشد می‌تواند با حسابت وارد شود. آن را به هیچ‌کس نفرست،
> توی چت نفرست، توی فایل عمومی نگذار و فقط توی Variables ریل‌وی
> واردش کن.

### ۵٫۳ وارد کردن متغیرها در Railway

توی سرویس، تب Variables، این سه مورد را اضافه کن:

- `TELETHON_API_ID` = همان api_id (عدد)
- `TELETHON_API_HASH` = همان api_hash
- `TELETHON_SESSION_STRING` = همان رشته StringSession

بعد از ذخیره، سرویس دوباره دیپلوی می‌شود. توی `/start` ربات
می‌نویسد «ارسال فایل بزرگ (MTProto) فعال است».

### ۵٫۴ نکته‌ها و هشدار مهم

- این سشن متعلق به یک **حساب کاربری** است، نه ربات. ربات هنوز
  با `BOT_TOKEN` کار می‌کند و لینک‌ها را می‌گیرد؛ فقط ارسال
  فایل‌های بزرگ با حساب کاربری انجام می‌شود.
- حساب کاربری Telethon باید عضو گروه باشد تا بتواند توی گروه
  فایل بفرستد؛ برای پی‌وی هم باید با گیرنده دیالوگ داشته باشد.
  اگر این‌طور نباشد، ارسال با Telethon ناموفق می‌شود و ربات
  خودکار برمی‌گردد به همان مسیر تیکه‌تیکه کردن.
- ⚠️ استفاده از حساب کاربری به‌جای ربات **خلاف قوانین تلگرام
  است** و حساب ممکن است محدود یا بن شود؛ دقیقاً مثل سلف‌بات.
  پس این بخش را با حسابت اصلی‌ات فعال نکن؛ اگر می‌خواهی، با یک
  حساب جداگانه که برایت مهم نیست این کار را بکن.
- اگر هر سه متغیر ست نباشند، ربات کاملاً بدون Telethon کار
  می‌کند و چیزی خراب نمی‌شود.

## نکته‌ها

- اینستا و پورن‌هاب گاهی جلوی دانلود رو می‌گیرن؛ اگه یه لینک نشد،
  لینک دیگه رو امتحان کن. برای محتوای خصوصی و نیازمند لاگین، توی این نسخه
  لاگین نیست و دانلود نمی‌شه.
- سقف ۵۰ مگابایت تلگرام سقفی سخت است؛ ربات کیفیت را پایین می‌آورد،
  اگر Telethon فعال باشد فایل بزرگ را مستقیم تا ۲ گیگابایت
  می‌فرستد، و در غیر این صورت ویدیو را تیکه‌تیکه می‌کند؛ ولی
  تضمینی نیست که هر ویدیوی خیلی طولانی‌ای حتماً ارسال شود.
- اگه ربات توی گروه جواب نداد، اول Privacy Mode رو چک کن (بالا).
